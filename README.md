# 息壤引擎 · Xirang Engine

> AI 原生软件工厂 —— 从需求到上线,一条流水线。

陕西息壤引擎科技发展有限公司的工程组织。我们用 AI Agent 驱动软件开发的全流程:
需求分析 → 代码生成 → 多端构建(Windows/macOS/Linux/Android/iOS/微信小程序)→
自动部署 → 运维诊断,全部由自研的自动化开发平台完成。

## 我们在做什么

- **百灵数字员工(Myna.bot)** —— AI 员工平台:数字员工在真实电脑上工作,
  视觉理解 + 浏览器操作 + 本地 ASR/判据引擎,一个员工一个岗位
- **自动化开发平台** —— 需求进、产品出:多项目多环境管理、远端构建矩阵、
  域名/证书/存储一键开通,本 org 里的大部分仓库由它生成与维护
- **快系列** —— 快录 / 快知 / 快咔 / 快客 / 快队 …… 一批垂直场景的 AI 工具产品
- **SaaS 矩阵** —— 面向中小企业的垂直获客站与经营工具
